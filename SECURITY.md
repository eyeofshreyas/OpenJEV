# Security Policy

## Reporting a Vulnerability

If you find a security issue in this project, please report it privately
rather than opening a public issue: use GitHub's
["Report a vulnerability"](https://github.com/eyeofshreyas/OpenJEV/security/advisories/new)
flow on this repo.

Include what you found, how to reproduce it, and its potential impact.
We'll acknowledge the report and follow up once it's assessed.

## Supported Versions

This project has no tagged releases yet; security fixes land on `main`.
